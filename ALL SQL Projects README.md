#                   ~ MIMIC-IV Relational Database Analysis ~

**Analyzed and tabled hospital stay data by diagnoses and health factors from relational database 
in SQL Workbench and Snowflake**

*Original Study Publication: Johnson, A.E.W., Bulgarelli, L., Shen, L. et al. MIMIC-IV, a freely accessible electronic health record dataset. Sci Data 10, 1 (2023). https://doi.org/10.1038/s41597-022-01899-x https://doi.org/10.1038/s41597-022-01899-x*

*Data Source: Johnson, A., Bulgarelli, L., Pollard, T., Gow, B., Moody, B., Horng, S., Celi, L. A., & Mark, R. (2024). MIMIC-IV (version 3.1). PhysioNet. RRID:SCR_007345. https://doi.org/10.13026/kpb9-mt58*

*Reference & Codebook: Massachusetts Institute of Technology. (2023). MIMIC Data. MIT 
Laboratory for Computational Physiology. https://mimic.mit.edu/docs/iv/*

# Associated Files - How to Run
1. Determine if you want to work in parts or combined scripts [SmithA_hospitalanalysis_Combine.sql]
2. Download appropriate files into one area
3. Download and import dataset from the MIMIC-IV link as the direct dataset is not in this repository
4. Open and run the combined file or [SmithA_hospitalanalysis_tables.sql] first
5. If working in parts open and run [SmithA_hospitalanalysis_diagnosis] next
